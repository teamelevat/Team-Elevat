Reference architecture

Keep the control plane understandable.

Start with a trusted local runtime. Add hosted components only when there is a clear need for remote availability, and preserve state with durable storage.

Local host
Primary agent runtime and local tools.
Hosted endpoint
Optional public-facing service with authentication.
Persistent state
